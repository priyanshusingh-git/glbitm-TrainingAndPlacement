# GL Bajaj Institute of Technology & Management
## Training & Placement Portal

Repository containing the official Training & Placement web portal, database schemas, and documentation.

---

## 📁 Repository Structure

- **`portal/`**: Next.js 16 web application with Tailwind CSS, Prisma, and design-system components.
  - See [`portal/README.md`](./portal/README.md) for full setup instructions and development commands.
- **`docs/`**: Comprehensive system specifications and problem-solving logs.
  - [`docs/DESIGN_SYSTEM_v2.md`](./docs/DESIGN_SYSTEM_v2.md): Master Design System reference (Colors, Typography, Radius, Shadows, Skeleton Loaders, Sidebar Architecture).
  - [`docs/problems-and-fixes/`](./docs/problems-and-fixes/): Development troubleshooting log and architectural decisions.

---

## ⚡ Key Highlights
- **0ms Instant Navigation**: Optimistic `SidebarContext` state coordination with layout-matched skeleton loaders.
- **Prestige Institutional Theme**: Deep teak brown (`#512912`) and warm amber gold (`#E8A020`) tokens with `Fraunces` serif headings and `Inter` precision data tables.
- **Role-Based Workflows**: Tailored portals for Students, Admins, Trainers, and Recruiters.
